1. キーを生成します:
```bash
ssh-keygen -t ed25519 -C "u12s20@gmail.com"
```
保存場所とパスフレーズは、そのままEnterでも構いません。

2. 公開鍵をコピーします:
```bash
cat ~/.ssh/id_ed25519.pub
```
表示された内容(`ssh-ed25519`で始まる1行)をコピーします。

3. GitHubの Settings → SSH and GPG keys → New SSH key を開き、Titleに任意の名前、Keyにコピーした内容を貼り付けて保存します。

4. 動作確認:
```bash
ssh -T git@github.com
```
「Hi ユーザー名! You've successfully authenticated」と出れば完了です。
