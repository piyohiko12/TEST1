ターミナルで次の手順を実行します。

**1. SSHキーを生成する**
```bash
ssh-keygen -t ed25519 -C "u12s20@gmail.com"
```
保存先を聞かれたらEnter(デフォルトの`~/.ssh/id_ed25519`)、パスフレーズは任意で設定します。

**2. 公開鍵をコピーする**
```bash
cat ~/.ssh/id_ed25519.pub
```
表示された`ssh-ed25519 ...`の行全体をコピーします(macOSなら`pbcopy < ~/.ssh/id_ed25519.pub`で直接クリップボードへ)。

**3. GitHubに登録する**
GitHubのSettings → SSH and GPG keys → New SSH key を開き、コピーした公開鍵を貼り付けて保存します。

**4. 接続を確認する**
```bash
ssh -T git@github.com
```
`Hi <ユーザー名>! You've successfully authenticated`と出れば完了です。

以降はリポジトリのURLをSSH形式(`git@github.com:user/repo.git`)にすればパスワードなしで操作できます。
