1. キーを生成: `ssh-keygen -t ed25519 -C "u12s20@gmail.com"`
保存先とパスフレーズを聞かれますが、Enterで既定のまま進めて構いません。

2. 公開鍵をコピー: `cat ~/.ssh/id_ed25519.pub` の出力(`ssh-ed25519 ...`で始まる1行)をすべてコピーします。

3. GitHubに登録: Settings → SSH and GPG keys → New SSH key を開き、コピーした内容を Key 欄に貼り付けて保存します。

4. 接続確認: `ssh -T git@github.com` を実行し、`Hi <ユーザー名>!` と表示されれば完了です。
