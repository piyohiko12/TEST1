GitHubで使うSSHキーを作って登録する手順は次の通りです。

**1. キーを生成する**

```bash
ssh-keygen -t ed25519 -C "u12s20@gmail.com"
```

保存先(そのままEnterで`~/.ssh/id_ed25519`)とパスフレーズを聞かれるので入力します。パスフレーズは省略可ですが設定を推奨します。

**2. 公開鍵をコピーする**

```bash
cat ~/.ssh/id_ed25519.pub
```

表示された内容(`ssh-ed25519 ...`)をすべてコピーします。

**3. GitHubに登録する**

GitHubのSettings → SSH and GPG keys → New SSH key を開き、Titleに端末名など任意の名前、Keyに先ほどの公開鍵を貼り付けてAdd SSH keyを押します。

**4. 接続を確認する**

```bash
ssh -T git@github.com
```

`Hi <ユーザー名>! You've successfully authenticated...`と出れば成功です。

以降、リポジトリのURLを`git@github.com:ユーザー名/リポジトリ.git`形式(SSH)にすればパスワード入力なしで操作できます。
