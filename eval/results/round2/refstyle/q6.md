1. キーを生成します(メールはGitHubアカウントのものに):

```bash
ssh-keygen -t ed25519 -C "u12s20@gmail.com"
```

保存場所とパスフレーズを聞かれますが、そのままEnterで進めても構いません。

2. 公開鍵をコピーします:

```bash
cat ~/.ssh/id_ed25519.pub
```

表示された1行(`ssh-ed25519`で始まる)をコピーします。

3. GitHubの Settings → SSH and GPG keys → New SSH key を開き、Titleに識別名(例: 自分のPC名)を入れ、Keyにコピーした公開鍵を貼り付けて保存します。

4. 動作確認:

```bash
ssh -T git@github.com
```

`Hi ユーザー名!` と表示されれば完了です(初回は接続確認を聞かれるので`yes`と入力)。
