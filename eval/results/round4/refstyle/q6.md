1. キーを生成します(メールはGitHub登録のもの):
```bash
ssh-keygen -t ed25519 -C "u12s20@gmail.com"
```
保存先とパスフレーズはEnterでデフォルトのままで構いません。

2. 公開鍵をコピーします:
```bash
cat ~/.ssh/id_ed25519.pub
```
表示された1行(`ssh-ed25519`で始まる)を全部コピーします。

3. GitHubの Settings → SSH and GPG keys → New SSH key を開き、Titleに端末名など任意の名前を付け、Keyに貼り付けて保存します。

4. 接続を確認します:
```bash
ssh -T git@github.com
```
「Hi ユーザー名!」と表示されれば登録完了です。
