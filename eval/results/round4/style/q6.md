まずローカルでキーを生成し、公開鍵をGitHubに登録します。

**1. キーを生成する**

```bash
ssh-keygen -t ed25519 -C "u12s20@gmail.com"
```

保存先(そのままEnterで`~/.ssh/id_ed25519`)とパスフレーズを聞かれます。パスフレーズは空でも進めますが、設定を推奨します。

**2. 公開鍵をコピーする**

```bash
cat ~/.ssh/id_ed25519.pub
```

表示された`ssh-ed25519 ...`の1行をすべてコピーします(末尾の`.pub`が公開鍵で、これを登録します。`.pub`が付かないファイルは秘密鍵なので絶対に共有しないでください)。

**3. GitHubに登録する**

GitHubで Settings → SSH and GPG keys → New SSH key を開き、Titleに任意の名前、Keyにコピーした内容を貼り付けて Add SSH key を押します。

**4. 接続を確認する**

```bash
ssh -T git@github.com
```

`Hi ユーザー名! You've successfully authenticated...`と出れば完了です。以降はリポジトリのURLを`git@github.com:...`形式(SSH)にすればパスワード入力なしで操作できます。
