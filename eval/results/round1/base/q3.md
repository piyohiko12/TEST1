# HTTPとHTTPSの違い

## 基本的な違い

**HTTP（HyperText Transfer Protocol）**
- Webブラウザとサーバー間でデータをやり取りする通信規約
- データが**暗号化されない**ため、通信内容が第三者に見られる可能性がある

**HTTPS（HTTP Secure）**
- HTTPに**暗号化（SSL/TLS）**を加えたもの
- 通信内容が暗号化され、安全にやり取りできる

## 主な違いの比較

| 項目 | HTTP | HTTPS |
|------|------|-------|
| 暗号化 | なし | あり（SSL/TLS） |
| ポート番号 | 80 | 443 |
| セキュリティ | 低い | 高い |
| URL表記 | `http://` | `https://` |
| 証明書 | 不要 | 必要（SSL証明書） |

## HTTPSのメリット

1. **盗聴の防止** - 通信内容が暗号化される
2. **改ざんの防止** - データが途中で書き換えられていないか検証できる
3. **なりすまし防止** - 証明書により正規のサイトであることを確認できる

## 補足

現在は、パスワードやクレジットカード情報など機密性の高い情報を扱わないサイトでも、**HTTPSが標準**となっています。Google Chromeなどのブラウザでは、HTTP接続のサイトに「保護されていない通信」という警告が表示されます。
