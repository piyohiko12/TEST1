SSHキーを作成してGitHubに登録する手順を説明します。

## 1. 既存のSSHキーを確認

まず、すでにキーがないか確認します。

```bash
ls -al ~/.ssh
```

`id_ed25519` や `id_ed25519.pub` などがあれば、既存のキーが使えます。

## 2. SSHキーを生成

```bash
ssh-keygen -t ed25519 -C "u12s20@gmail.com"
```

- **保存場所**: そのままEnterでデフォルト（`~/.ssh/id_ed25519`）でOK
- **パスフレーズ**: 任意（設定推奨。空でもEnterで進めます）

> 古い環境でed25519が使えない場合は代わりに:
> ```bash
> ssh-keygen -t rsa -b 4096 -C "u12s20@gmail.com"
> ```

## 3. ssh-agentに鍵を登録（任意だが推奨）

```bash
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519
```

## 4. 公開鍵をコピー

**macOS:**
```bash
pbcopy < ~/.ssh/id_ed25519.pub
```

**Linux (xclip):**
```bash
xclip -selection clipboard < ~/.ssh/id_ed25519.pub
```

**Windows (Git Bash):**
```bash
clip < ~/.ssh/id_ed25519.pub
```

うまくいかない場合は `cat ~/.ssh/id_ed25519.pub` で表示して手動コピーしてください。

## 5. GitHubに登録

1. GitHubにログイン
2. 右上のアイコン → **Settings**
3. 左メニューの **SSH and GPG keys**
4. **New SSH key** をクリック
5. **Title**（例: MacBook）を入力し、**Key** 欄に貼り付け
6. **Add SSH key** をクリック

## 6. 接続テスト

```bash
ssh -T git@github.com
```

以下のように表示されれば成功です:

```
Hi <ユーザー名>! You've successfully authenticated...
```

---

**補足**: 以降、リポジトリのクローンやリモート設定はHTTPSではなくSSH形式（`git@github.com:ユーザー名/リポジトリ.git`）を使ってください。

不明な点があれば、お使いのOSを教えていただければより詳しく案内します。
