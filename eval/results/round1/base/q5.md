PythonでCSVファイルを読み込んで各行を表示するコードをいくつかの方法でご紹介します。

## 方法1: `csv`モジュール（標準ライブラリ）

```python
import csv

with open('data.csv', 'r', encoding='utf-8') as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)  # 各行がリストとして表示される
```

## 方法2: ヘッダーを使って辞書として読み込む

```python
import csv

with open('data.csv', 'r', encoding='utf-8') as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row)  # 各行が {列名: 値} の辞書として表示される
```

## 方法3: `pandas`を使う（データ分析向け）

```python
import pandas as pd

df = pd.read_csv('data.csv', encoding='utf-8')

# 各行を1行ずつ表示
for index, row in df.iterrows():
    print(row.to_dict())

# または全体を表示
print(df)
```

## 補足ポイント

- **`encoding`**: 日本語を含むCSVは `utf-8` や `shift_jis`（Excelで作成した場合など）を指定します
- **`csv`モジュール**: 標準ライブラリなのでインストール不要。カンマや引用符を正しく処理してくれます
- **`pandas`**: `pip install pandas` が必要ですが、大量データの処理や集計に便利です
