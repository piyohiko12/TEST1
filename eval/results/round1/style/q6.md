SSHキーの作成からGitHub登録までは4ステップです。

## 1. キーを作成する

ターミナルで次のコマンドを実行します(メールアドレスは自分のものに置き換え)。

```bash
ssh-keygen -t ed25519 -C "u12s20@gmail.com"
```

保存場所を聞かれたらEnterでデフォルト(`~/.ssh/id_ed25519`)のまま。パスフレーズは任意ですが、設定しておくと安全です。

古い環境でed25519が使えない場合のみ `ssh-keygen -t rsa -b 4096 -C "..."` を使ってください。

## 2. ssh-agentに登録する(任意だが推奨)

パスフレーズの再入力を省けます。

```bash
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519
```

## 3. 公開鍵をコピーする

**公開鍵(`.pub`のほう)** を表示してコピーします。秘密鍵は絶対に他人へ渡さないでください。

```bash
# macOS
pbcopy < ~/.ssh/id_ed25519.pub

# Linux (xclip導入時)
xclip -sel clip < ~/.ssh/id_ed25519.pub

# Windows (Git Bash)
clip < ~/.ssh/id_ed25519.pub
```

うまくいかなければ `cat ~/.ssh/id_ed25519.pub` で表示して手動コピーでも構いません。

## 4. GitHubに登録して確認する

1. GitHubの **Settings → SSH and GPG keys → New SSH key** を開く
2. Titleに端末名など任意の名前を入れ、Keyにコピーした内容を貼り付けて **Add SSH key**
3. 接続テスト:

```bash
ssh -T git@github.com
```

`Hi <ユーザー名>! You've successfully authenticated...` と出れば成功です。以降はリポジトリのURLをSSH形式(`git@github.com:ユーザー名/リポジトリ.git`)にすればパスワードなしで操作できます。
