```python
import csv

with open("data.csv", newline="", encoding="utf-8") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)
```

各行は文字列のリスト（例: `['田中', '30', '東京']`）として表示されます。

補足が必要そうな点を2つ:

- **ヘッダー行を辞書として扱いたい場合**は `csv.DictReader` が便利です。1行目を見出しにして各行を `{'名前': '田中', ...}` の形で取れます。
- **文字コード**は日本語CSVだと `utf-8` で文字化けすることがあります。その場合は Excel由来のファイルなら `encoding="cp932"` を試してください。

ファイル名や区切り文字（タブ区切りなど）が違う場合は教えてください。
