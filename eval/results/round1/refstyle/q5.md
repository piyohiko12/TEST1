```python
import csv

with open("data.csv", encoding="utf-8", newline="") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)
```

`row`は各行を文字列のリスト(例: `['名前', '年齢']`)として返します。列名でアクセスしたい場合は`csv.DictReader`に替えると、各行が`{'名前': '田中', '年齢': '30'}`のような辞書になります。Excel由来のCSVで文字化けする場合は`encoding="cp932"`を試してください。
