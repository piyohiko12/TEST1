手順は3つです。

**1. キーを作成**
```bash
ssh-keygen -t ed25519 -C "u12s20@gmail.com"
```
保存場所はEnterでデフォルト(`~/.ssh/id_ed25519`)、パスフレーズは任意です。

**2. 公開鍵をコピー**
```bash
cat ~/.ssh/id_ed25519.pub
```
表示された`ssh-ed25519 AAAA...`で始まる1行全体をコピーします(macOSなら`pbcopy < ~/.ssh/id_ed25519.pub`で直接コピー可能)。

**3. GitHubに登録**
GitHubの Settings → SSH and GPG keys → New SSH key を開き、Titleに任意の名前(例: MacBook-2026)、Key欄にコピーした公開鍵を貼り付けて保存します。

**動作確認**
```bash
ssh -T git@github.com
```
`Hi ユーザー名! You've successfully authenticated...`と出れば完了です。初回接続時にフィンガープリントの確認を求められたら`yes`と入力してください。

注意点は1つだけ:登録するのは`.pub`が付いた公開鍵です。`.pub`なしの秘密鍵は誰にも渡さないでください。
