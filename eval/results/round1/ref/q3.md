# HTTPとHTTPSの違い

## 基本的な違い

**HTTP(HyperText Transfer Protocol)**
- Webブラウザとサーバー間でデータをやり取りするための通信プロトコル
- 通信内容が**暗号化されない**(平文で送信される)

**HTTPS(HTTP Secure)**
- HTTPに**SSL/TLS**という暗号化技術を組み合わせたもの
- 通信内容が**暗号化される**

## 主な違いの比較

| 項目 | HTTP | HTTPS |
|------|------|-------|
| 暗号化 | なし | あり(SSL/TLS) |
| ポート番号 | 80 | 443 |
| URL | `http://` | `https://` |
| 証明書 | 不要 | SSL/TLS証明書が必要 |
| セキュリティ | 低い | 高い |

## HTTPSのメリット

1. **盗聴の防止**
   通信が暗号化されるため、第三者に内容を見られない(パスワードやクレジットカード情報など)

2. **改ざんの防止**
   通信途中でデータが書き換えられていないことを保証

3. **なりすましの防止**
   証明書により、接続先が本物のサイトであることを確認できる

4. **SEO・信頼性の向上**
   検索エンジンはHTTPSサイトを優遇し、ブラウザもHTTPサイトに「保護されていない通信」と警告を表示

## 現在の状況

現在では、個人情報を扱うページだけでなく**サイト全体をHTTPS化する「常時SSL化」が標準**となっています。ブラウザのアドレスバーに鍵マーク🔒が表示されていれば、HTTPSで通信していることを意味します。
