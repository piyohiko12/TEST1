PythonでCSVファイルを読み込んで各行を表示する方法をいくつか紹介します。

## 方法1: 標準ライブラリの `csv` モジュールを使う

```python
import csv

with open('data.csv', 'r', encoding='utf-8') as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)
```

各行はリスト（例: `['名前', '年齢', '住所']`）として取得されます。

## 方法2: ヘッダー付きCSVを辞書として読み込む

```python
import csv

with open('data.csv', 'r', encoding='utf-8') as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row)
```

1行目をヘッダーとして扱い、各行を辞書（例: `{'名前': '田中', '年齢': '30'}`）で取得できます。

## 方法3: pandas を使う

```python
import pandas as pd

df = pd.read_csv('data.csv', encoding='utf-8')

for index, row in df.iterrows():
    print(row.to_dict())
```

※ pandasは事前に `pip install pandas` でインストールが必要です。

## 補足

- **Excelで作成したCSV**の場合、文字化けするときは `encoding='shift_jis'` や `encoding='cp932'` を試してください
- ファイルが見つからないエラーに備えるなら、以下のようにできます:

```python
import csv

try:
    with open('data.csv', 'r', encoding='utf-8') as f:
        reader = csv.reader(f)
        for row in reader:
            print(row)
except FileNotFoundError:
    print('ファイルが見つかりません')
```

用途に応じて選んでください。シンプルな読み込みなら方法1、データ分析をするなら方法3がおすすめです。
