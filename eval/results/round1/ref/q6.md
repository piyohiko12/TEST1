# SSHキーを作成してGitHubに登録する手順

## 1. SSHキーの作成

ターミナルで以下のコマンドを実行します:

```bash
ssh-keygen -t ed25519 -C "u12s20@gmail.com"
```

※ 古いシステムでEd25519が使えない場合は以下を使用:

```bash
ssh-keygen -t rsa -b 4096 -C "u12s20@gmail.com"
```

プロンプトが表示されたら:
- **保存場所**: Enterキーでデフォルト(`~/.ssh/id_ed25519`)を使用
- **パスフレーズ**: 設定推奨(空でも可)

## 2. SSHエージェントに鍵を追加

```bash
# エージェントを起動
eval "$(ssh-agent -s)"

# 鍵を追加
ssh-add ~/.ssh/id_ed25519
```

**macOSの場合**は `~/.ssh/config` に以下を追記しておくと便利です:

```
Host github.com
  AddKeysToAgent yes
  UseKeychain yes
  IdentityFile ~/.ssh/id_ed25519
```

そして `ssh-add --apple-use-keychain ~/.ssh/id_ed25519` で追加します。

## 3. 公開鍵をコピー

```bash
# macOS
pbcopy < ~/.ssh/id_ed25519.pub

# Linux(xclipがある場合)
xclip -selection clipboard < ~/.ssh/id_ed25519.pub

# Windows (Git Bash)
clip < ~/.ssh/id_ed25519.pub
```

コピーできない場合は `cat ~/.ssh/id_ed25519.pub` で表示して手動コピーします。

## 4. GitHubに登録

1. GitHubにログイン
2. 右上のアイコン → **Settings**
3. 左メニューの **SSH and GPG keys**
4. **New SSH key** をクリック
5. **Title**: 分かりやすい名前(例: `MacBook Pro 2026`)
6. **Key type**: `Authentication Key` のまま
7. **Key**: コピーした公開鍵を貼り付け
8. **Add SSH key** をクリック

## 5. 接続テスト

```bash
ssh -T git@github.com
```

以下のようなメッセージが出れば成功です:

```
Hi ユーザー名! You've successfully authenticated, but GitHub does not provide shell access.
```

## 補足

- 既存リポジトリをHTTPSからSSHに切り替える場合:
  ```bash
  git remote set-url origin git@github.com:ユーザー名/リポジトリ名.git
  ```
- **秘密鍵(`id_ed25519`)は絶対に他人に渡さない**でください。GitHubに登録するのは `.pub` が付いた**公開鍵**の方です。
